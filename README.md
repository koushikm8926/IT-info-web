# Innovexa Systems — Modern Web Platform

A high-performance enterprise web application for **Innovexa Systems**, covering IT Services, IT Consulting, Staffing & Recruitment, and Innovexa Edutech.

Built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons & Motion**: [Lucide React](https://lucide.dev/)
- **State & Data**: Centralized typed dataset in `src/data/site-data.ts`
- **Recommended Backend**: Supabase (PostgreSQL, Storage, Auth)

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 3. Production Build
```bash
npm run build
npm run start
```
